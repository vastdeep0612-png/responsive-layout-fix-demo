Elementor-style mobile layout repair

A copied section with three common layout faults: sideways overflow, an overlapping button, and uneven spacing. The same section is shown before and after the repair at 375px, 768px, and 1440px.

Problem

On a phone the hero is wider than the screen, the menu stays on one line, and the button sits on top of the heading. At tablet width the cards keep a fixed gap that pushes the row out of line. This is a standalone reproduction of faults that show up when an Elementor section is given a fixed pixel width.

Cause

The broken hero uses width: 1200px and box-sizing: content-box. The menu uses white-space: nowrap. The button is position: absolute. The second card has an extra margin-left: 80px.

Fix

The hero uses max-width: 100% and box-sizing: border-box. The menu wraps. The button returns to normal flow. The cards use one consistent gap.
